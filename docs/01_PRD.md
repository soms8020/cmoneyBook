# 📋 Product Requirements Document (PRD)
## 경조사비 관리 앱 - "경조사 장부"

---

## 1. 제품 개요

### 1.1 제품 비전
한국 사회에서 중요한 상부상조 문화인 경조사비를 체계적으로 관리하여, 적절한 금액의 경조사비를 주고받을 수 있도록 돕는 웹 애플리케이션.

### 1.2 문제 정의
- 경조사비를 지급하거나 받은 내역을 기억하기 어려움
- 누구에게 얼마를 받았는지, 줬는지 파악이 안 됨
- 상호 간 적절한 금액 산정이 어려움
- 종이 장부나 엑셀 관리의 비효율성

### 1.3 목표 사용자
- 20~60대 직장인 및 가정 주부
- 경조사가 빈번한 사회인
- PC와 모바일 기기를 사용하는 사용자

### 1.4 핵심 가치
| 가치 | 설명 |
|------|------|
| **편의성** | 언제 어디서든 PC/모바일로 빠르게 기록 |
| **투명성** | 주고받은 내역을 한눈에 파악 |
| **적정성** | 과거 데이터 기반 적절한 금액 추천 |
| **지속성** | 클라우드 DB로 데이터 영구 보존 |

## 2. 기능 요구사항

### 2.1 핵심 기능 (MVP)

#### F-000: 회원가입 및 로그인 (인증)
- 이메일/비밀번호 기반 회원가입
- JWT 토큰 기반 로그인 및 자동 로그인 지원
- 로그아웃 기능
- 사용자별 독립적인 데이터(인물, 내역) 관리

#### F-001: 경조사비 지출 기록
- 경조사 유형 선택 (결혼, 장례, 돌잔치, 생일, 승진, 개업 등)
- 대상자 정보 입력 (이름, 관계)
- 금액 입력
- 날짜 입력
- 메모 입력 (선택)

#### F-002: 경조사비 수입 기록
- 경조사 유형 선택
- 보내는 사람 정보 (이름, 관계)
- 금액 입력
- 날짜 입력
- 메모 입력 (선택)

#### F-003: 인물별 내역 조회
- 특정 인물과의 경조사비 주고받은 이력 조회
- 인물별 총 지출/수입 잔액 표시
- 관계 유형별 필터링

#### F-004: 대시보드
- 총 지출/수입 요약
- 월별/연도별 통계
- 최근 경조사 내역
- 관계별 통계 차트

#### F-005: 인물 관리
- 인물 등록/수정/삭제
- 관계 유형 설정 (가족, 친구, 직장동료, 지인 등)
- 소속 그룹 설정 (선택)

### 2.2 부가 기능 (v2.0)

#### F-006: 경조사비 추천
- 과거 데이터 기반 적정 금액 추천
- 관계, 경조사 유형별 평균 금액 제시

#### F-007: 검색 및 필터
- 이름, 기간, 금액, 유형별 검색
- 복합 필터링 지원

#### F-008: 데이터 내보내기
- CSV/Excel 내보내기
- 인쇄 기능

## 3. 비기능 요구사항

### 3.1 성능
- 페이지 초기 로딩: 3초 이내
- API 응답 시간: 500ms 이내
- 동시 접속: 최소 100명

### 3.2 보안
- HTTPS 통신
- 비밀번호 암호화 (bcrypt)
- JWT 기반 API 인증 및 접근 제어
- SQL Injection 방지 (Drizzle ORM)
- SQL Injection 방지 (Drizzle ORM)

### 3.3 호환성
- Chrome, Safari, Firefox, Edge 최신 버전
- 모바일: iOS Safari, Android Chrome
- 반응형 디자인: 320px ~ 2560px

### 3.4 접근성
- WCAG 2.1 Level AA 준수
- 키보드 네비게이션
- 스크린 리더 호환
